# Grant Proposal And Figure Alignment

Use the current call, template and author materials as the authority. Read them before drafting. Extract scope, headings, word-count rules, anonymity, eligible outputs, timeline and submission format. Requirements differ between schemes and years; do not carry numeric limits from a past project.

## Research Design

Create a mapping from call requirement to real problem, research question, task, method/data, validation and output. Read [design mapping](references/design-mapping.md). Preserve the user's established structure when requested; refine transitions and task boundaries within it.

Distinguish parallel modules from sequential modules. For parallel modules, state the shared comparison dimensions. For sequential modules, name the previous output that becomes the next input. Each module needs a feasible evidence path and an output used by the overall project.

Relate policy context to a concrete decision problem and responsible actor. Verify time-sensitive policy names/status using official sources when drafting actual claims. National, municipal and university proposals need different objects, decision interfaces and feasible scopes; changing place names alone is insufficient.

## Figure Plan

Use one overall framework/technical route and module-level figures when they add detail. Match figure names, labels and module order to the prose. Black/white SVG is a useful default for compact application documents; follow the user's supplied visual reference. Use the publication-chart skill if available, otherwise apply measured text fitting, equal peer boxes and rendered QA directly.

Prepare a figure register: caption, insertion point, supporting text, arrow meaning, source SVG and preview. When the user requests separate assets, deliver text and figures separately. If PowerPoint-level object editing is requested, distinguish native shapes from an embedded SVG.

## Integrity And Template Delivery

Use planned language for unperformed research. Interviews, coding counts, saturation, effect estimates and prior achievements require actual records. Keep illustrative designs distinct from empirical findings.

Preserve required template headings, fields and counting rules. Anonymous submissions need checks of visible text, images, document properties, comments and tracked changes. Render the final document and inspect page breaks and figure readability. A `.doc` request requires an actual format conversion, not a renamed `.docx`.

Deliver the proposal/design map, figure register and source assets requested by the user, with unresolved evidence and template constraints stated precisely.
