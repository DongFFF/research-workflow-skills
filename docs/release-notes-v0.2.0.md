# v0.2.0 Management Abstract Writing

Adds `management-abstract-writing`, a reusable skill for management journal abstracts, including corporate sustainability and configurational research.

- Connects substantive necessity, coordination difficulties, method rationale, evidence and concrete implications for a named decision-maker.
- Explains why combinations merit examination when conditions are interdependent, without treating configurational methods as universally required.
- Distinguishes association, necessity, consistency, coverage, mechanisms and temporal fit.
- Preserves user-approved sections and copy-only delivery requests.
- Treats journal limits as current requirements to verify and distinguishes whitespace counts from a destination application's count.

The examples are synthetic. No unpublished manuscript text, empirical data, author details or local runtime bundles are included.

The standalone ZIP contains the skill folder and its MIT license. The collection installer can install it with:

```sh
python tools/install_skills.py --skill management-abstract-writing
```

Example request:

```text
Use $management-abstract-writing to revise this abstract so its findings lead to a concrete managerial assessment or decision.
```
