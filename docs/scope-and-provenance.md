# Scope And Provenance

This release curates the user's local research skills and abstracts repeatable practices from several manuscript and grant workflows. It does not copy third-party installed plugin skills or project datasets.

| Local capability reviewed | Release decision |
| --- | --- |
| Publication figures and tables | Retain the skill name, shorten instructions, preserve SVG geometry and typography preferences, provide a portable generator |
| Zotero DOCX references | Retain the skill name, remove account/path/proxy constants, replace fragile paragraph counting with field parsing |
| National, municipal and university grant applications | Extract template-driven question/task/method/data/output mapping into a new skill |
| Management research abstract revision | Extract problem necessity, method rationale and evidence-to-decision implications into a new skill; include synthetic fragments only |
| Visio automation | Inventory only; local package provenance needs separate review before redistribution |
| Other academic/review/analysis skills | Complementary local tools, outside the focus of this release |
| Bundled document, PDF, presentation and browser plugins | External dependencies; no redistribution |

Practices were reviewed in procurement-demand, enterprise sustainability, digital/green transformation and grant-application workflows. Public examples use newly written generic labels. No original prose, empirical results, unpublished research graphics, private thread transcripts, personal paths, or Zotero identities are included.

The public skills intentionally revise environment-specific habits: proxy configuration is discovered rather than fixed; citation styles follow the journal before a default; item identity is distinct from citation numbering; network errors are recorded as access failures, not invalid literature; command dispatch is distinct from completed refresh.

The repository contains original workflow instructions and helper implementations. `pubfig`, `pubtab`, Zotero, Microsoft Word, fonts, renderers and any installed CSL styles are external works with their own terms. No claim is made over them, and their binaries or styles are not bundled.
