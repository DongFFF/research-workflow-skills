# v0.1.0

Initial public release of three research workflow skills:

- Publication figures: editable SVG frameworks, measured text layout, exact-redraw guidance, plot/table routing and rendered QA.
- Zotero and Word: Scholar-first discovery, DOI verification, collection/readback checks, identity-preserving citation maintenance and read-only DOCX auditing.
- Grant proposals: template-driven research design and question/task/method/data/output/figure alignment.

Includes Chinese and English documentation, a backup-aware installer, synthetic examples, 15 offline tests and GitHub Actions validation on Python 3.10 and 3.13.

Live Scholar, Zotero import and Word refresh are environment-dependent and are not claimed by the offline test suite. Existing local skills are not overwritten by publication. External runtimes, styles, account data and unpublished materials are excluded. MIT licensed.
